## Duplicate / Version Groups

- `EmpireRedeem`: multiple versions from `1.1.10` through `1.4.x`; not selected because the workspace also had stronger, more varied examples.
- `OtakuEmpireCore` and `OtakuEmpireCoreSMP`: many core versions; the full core was not copied.
- `OtakuAuctionHouse`: root project and an Eclipse export; the root project was more complete.
- `HeadSystem` / `ExampleSMP` / `ExampleNetwork` variants: treated as server-suite/core material, not copied as full projects.
- Shop variants: `ExampleNetworkShop`, `ExampleNetworkSMPShop`, `ExampleNetworkSurvivalShop`, `NovaShop`, `OtakuAdminShop`; similar domain, so not all were useful for a focused portfolio.
