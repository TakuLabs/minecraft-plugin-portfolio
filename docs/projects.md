# Project Notes

## Selected Plugins

### BirthdayEvent

Purpose: one-time birthday event plugin with scheduling, message configuration and reward claiming.

Portfolio value: demonstrates time-based event logic, YAML settings, Paper commands/listeners, persistent state and unit tests.

### EmpireCrates

Purpose: configurable crate system with rewards, GUIs and player progress.

Portfolio value: demonstrates a larger standalone gameplay plugin with models, storage, GUI handlers, command handling and PlaceholderAPI integration.

### OtakuAuctionHouse

Purpose: inventory-based player auction house.

Portfolio value: demonstrates economy integration, menu flow, serialized item storage and permission-based limits.

### NovaGuard

Purpose: server security plugin for IP limits, access lists and packet monitoring.

Portfolio value: demonstrates service separation, rate limiting, ProtocolLib integration, privacy-aware IP handling and unit tests.

### OtakuScoreboard

Purpose: configurable scoreboard and tablist plugin.

Portfolio value: demonstrates repeated UI updates, PlaceholderAPI usage, player toggles and configuration-driven rendering.
