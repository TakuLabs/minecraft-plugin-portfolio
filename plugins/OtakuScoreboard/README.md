# OtakuScoreboard

Configurable Paper scoreboard and tablist plugin.

## Features

- YAML-configured scoreboard lines
- PlaceholderAPI support
- Player toggle command
- Reload command
- Tablist and nametag services
- Optional rainbow tablist mode

## Requirements

- Java 21
- Paper 1.21.x
- Maven
- PlaceholderAPI optional/provided

## Building

```bash
mvn clean package
```

## Notes

This is a smaller showcase plugin for repeated UI updates, placeholders and player-facing commands.
